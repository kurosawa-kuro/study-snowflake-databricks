## 3. DB テーブル・リレーション

現時点では未実装。方針だけ固定している。

### 3.1 これから作るテーブル群

| 層 | 例 | 説明 |
|---|---|---|
| RAW | `raw_property_transactions` | GCS から着地した生データ |
| staging | `stg_property_transactions` | 型、列名、欠損を整えた層 |
| intermediate | `int_property_features` | join と派生列を加えた中間層 |
| mart | `mart_property_training` | Databricks 学習入力の主表 |
| serving | `pred_property_price` | 予測結果の書き戻し先 |

### 3.2 リレーション方針

- RAW は入力単位で分ける
- marts で Databricks が読む主表を 1 本に寄せる
- prediction 系は学習入力 mart と分離する
